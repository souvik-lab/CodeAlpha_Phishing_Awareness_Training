# Phishing_Awareness_Training

A comprehensive Phishing Awareness and Social Engineering Training module developed for the **CodeAlpha Cyber Security Internship** (Task 2). This repository includes training presentations, real-world attack case studies, and an interactive CLI assessment engine.

## Project Overview
This project delivers training materials and an interactive evaluation tool designed to train users on identifying social engineering tactics, analyzing look-alike domains, verifying suspicious communications, and following standard incident reporting protocols.

## Repository Contents
- **`Phishing_Awareness_Training.pdf`:** Visual slide deck covering phishing anatomy, deceptive vectors, case studies, and defensive email security practices.
- **`phishing_quiz.py`:** An interactive Python-based CLI knowledge check to test user awareness and decision-making.

## Core Topics Covered
- **Social Engineering Vectors:** Psychological manipulation triggers such as artificial urgency, fear, authority impersonation, and greed.
- **Recognizing Phishing Emails:** Sender address spoofing, typosquatting domains, generic greetings, and deceptive hyperlinks.
- **Identifying Fake Websites:** Homograph character attacks, subdomain trickery, and SSL/HTTPS certificate misconceptions.
- **Real-World Case Studies:** Business Email Compromise (BEC) and corporate Single Sign-On (SSO) credential harvesters.
- **Email Security Best Practices:** Multi-Factor Authentication (MFA) enforcement, link verification procedures, and SOC escalation workflows.
